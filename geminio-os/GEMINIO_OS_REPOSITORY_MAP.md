# Repository Map

## Important directories

- `app/` — Expo Router screens, tabs, product dashboards, Builder, auth, and utility routes.
- `components/` — reusable UI, shell, icon, capability, and responsive primitives.
- `hooks/` — authentication, settings, persistence, device, media, offline, and feature hooks.
- `lib/` — client contexts, tRPC client, provider boundaries, security, payment contracts, integrations, and state helpers.
- `server/_core/` — Express/tRPC bootstrap, auth, OAuth, LLM, storage, and infrastructure.
- `server/ai-core/` — AI routing, capability registry, providers, orchestration, persistence, gateway, security, destinations.
- `server/live-builder/` — workspace service, runtime, runner, control plane, persistence, preview gateway, and diagnostics.
- `shared/` — Zod schemas, typed contracts, capability declarations, and cross-layer types.
- `drizzle/` — schema, relations, and additive SQL migrations.
- `tests/` — unit, integration, contract, security, Builder, runner, and workflow tests.
- `scripts/` — CLI, environment loading, QR generation, and security audit utilities.
- `assets/` — app icons, splash, and platform assets.
